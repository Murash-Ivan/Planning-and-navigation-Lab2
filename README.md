# Lab-2

Лабораторная работа №2: реализация алгоритма движения по линии для IoTRobotWorld

Полная реализация серверного приложения на C# (WinForms) для управления мобильным роботом в симуляторе IoTRobotWorld по протоколу UDP.

Основные функции:
- Сетевое взаимодействие: Асинхронный прием UDP-пакетов в отдельном потоке, кастомный парсинг JSON без внешних библиотек.
- Безопасность парсинга: Внедрен метод `SafeParseInt` для предотвращения крашей приложения при получении пустых или некорректных данных на старте.
- Ручное управление: Полная поддержка ввода через ползунки (Force/Balance) и клавиатуру (WASD/Стрелки).

Автоматический режим:
- Фаза 0 (Поиск): Стохастическое блуждание со строгим чередованием направлений поворота для предотвращения зацикливания. Переход по коду смарт-камеры "2" или срабатыванию центрального датчика `l0`.
- Фаза 1 (Выравнивание): Фиксированный поворот на месте влево для ориентации робота вдоль трассы по часовой стрелке.
- Фаза 2 (Движение по линии): Реализация пропорционального регулятора (П-регулятора). Расчет взвешенного среднего отклонения на основе 5 датчиков яркости (веса: l3=+30, l1=+15, l0=0, l2=-15, l4=-30) с коэффициентом усиления и ограничением диапазона [-50; 50] для плавности.

Доработки для повышения робастности:
- Маскировка сенсоров у стен: Программное игнорирование показаний крайних датчиков линии (`l3`/`l4`), если ультразвуковые дальномеры (`d0`-`d7`) фиксируют препятствие ближе 10-12 см. Решает проблему ложного детектирования серой стены как черной линии в симуляторе.
- Обработка пунктирных участков: Сохранение последнего успешного угла поворота для движения по инерции при кратковременной потере линии. Возврат в Фазу 0 только после исчерпания лимита 100 тиков.
- Контекстное избегание препятствий: Проверка бампера и фронтальных дальномеров активна в Фазах 0 и 1, но намеренно отключена в Фазе 2, что позволяет роботу безопасно проходить узкие коридоры вплотную к стенам, не срываясь с трассы.

Другое:
- Визуализация всех 8 дальномеров, 5 датчиков линии, энкодеров и сырых JSON-данных в реальном времени.
- Логирование текущего состояния и примененных корректировок в статус-баре.
